# Light Chaser Animation Studios

> Light Chaser Animation Studios (追光动画) is a Chinese computer-animation film studio founded in March 2013 by Gary Wang (王微), founder and former CEO of the video platform Tudou, and headquartered in Beijing. The studio produces original CG animated feature films drawn from Chinese mythology, literature and history. It is a film-production company, not a technology vendor, and publishes no public API.

## APIs

Light Chaser Animation Studios publishes no public API. As of 2026-07-19 there is no developer portal, no API documentation, no API reference, no OpenAPI or AsyncAPI description, no SDKs or client libraries in any public package registry, no CLI, no MCP server, and no webhook or event surface. Probes of the studio's only public host returned 404 for every standard discovery path (`/.well-known/security.txt`, `/.well-known/openid-configuration`, `/.well-known/oauth-authorization-server`, `/.well-known/api-catalog`, `/.well-known/ai-plugin.json`, `/llms.txt`, `/robots.txt`, `/sitemap.xml`, `/wp-json/`).
